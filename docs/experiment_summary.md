# Python 科赫雪花递归绘制实验总结

## 一、实验目的

本次实验要求使用 Python 绘制科赫雪花，并根据输入的阶数生成 0～4 阶的不同图形。通过本次实验，学习递归函数的基本原理，掌握 turtle 绘图库的简单使用方法，进一步理解函数、循环和条件判断等 Python 基础知识。

## 二、实验过程

首先，我根据老师的要求了解了科赫雪花的基本结构。科赫雪花从一个等边三角形开始，通过不断细分线段，逐渐形成复杂的雪花图案。

接着，我使用 Python 的 turtle 绘图库编写程序，并定义 `koch_curve()` 递归函数。当阶数为 0 时，直接绘制一条直线；当阶数大于 0 时，将原来的线段分成三等份，通过画笔转向和递归调用生成四条更短的线段。

然后，我编写了 `draw_snowflake()` 函数，通过循环绘制三条科赫曲线，组成完整的雪花图形。同时增加用户输入功能，让程序能够根据输入的阶数绘制对应的科赫雪花。

## 三、实验测试结果

为了验证程序的正确性，我分别输入 0、1、2、3、4 进行测试。

| 测试阶数 | 线段数量 | 实际运行结果 |
|---|---:|---|
| 0 阶 | 3 | 成功绘制等边三角形 |
| 1 阶 | 12 | 成功绘制六角星状雪花 |
| 2 阶 | 48 | 成功绘制具有更多凸起的雪花 |
| 3 阶 | 192 | 成功绘制边缘更加复杂的雪花 |
| 4 阶 | 768 | 成功绘制更加精细的分形雪花 |

通过五组测试，可以看到随着递归阶数增加，雪花边缘的线段数量不断增加，图形也越来越复杂。

本次实验的五张运行截图保存在 `docs/screenshots/` 文件夹中。

## 四、实验中遇到的问题

在编写程序时，我一开始对递归函数的执行过程理解得不够清楚，特别是为什么一个函数可以在内部继续调用自身。

通过分析科赫曲线的绘制过程，我逐渐理解了递归结束条件以及递归调用的作用。每次递归都会把当前线段分解成更短的线段，直到阶数为 0 时才真正执行绘制操作。

此外，在将代码上传 GitHub 的过程中，还遇到了 SSL/TLS 网络连接失败的问题。后来通过检查网络代理，并使用 OpenSSL 连接方式，成功将 Python 程序上传到了 GitHub。

## 五、实验收获

通过本次实验，我进一步理解了 Python 递归函数的基本思想，认识到递归可以将一个复杂的问题分解为多个结构相同的小问题。

在绘制科赫雪花的过程中，我练习了 turtle 绘图库中画笔移动、角度旋转和窗口设置等操作，也巩固了函数定义、条件判断和循环结构等基础知识。

通过观察 0～4 阶科赫雪花的变化，我发现只需要不断重复相同的绘制规则，就能够生成越来越复杂的分形图案。这让我对递归算法有了更加直观的认识。

同时，我也进一步熟悉了 VS Code 和 GitHub 的使用，学会了保存代码、记录实验过程以及整理运行截图。

## 六、实验总结

本次实验成功使用 Python 的 turtle 绘图库和递归函数，实现了 0～4 阶科赫雪花的绘制，并通过五组测试验证了程序的基本正确性。

通过这次实验，我不仅掌握了简单的递归绘图方法，也提高了自己分析问题、编写程序和解决实际问题的能力。
